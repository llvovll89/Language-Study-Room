# 한글 발음 표기 규칙 (v1.1~)

학습자는 **한국어만 아는 사람**으로 가정합니다. 그래서 모든 외국어(일본어, 중국어, 영어)에 한글 발음을 붙이고, 그 안에 **높낮이**와 **속도(길이, 연음, 약음, 쉼)**를 기호로 표시합니다.
data에는 아래 기호로 적습니다. 화면에 보이는 모양은 `build.mjs`의 `renderPron()`이 만듭니다.

## 기호

| 의미 | data 표기 | 화면 | 쓰는 곳 |
|---|---|---|---|
| 높게 / 세게 | `[하요-]` | 윗줄과 굵은 글씨 | 일본어: 높은 음(악센트 핵까지) / 영어: 강세 음절 |
| 중국어 성조 | 음절 뒤 숫자 `1` `2` `3` `4` `0` | `→ ↗ ↘↗ ↘ ·` 작은 기호 | 중국어 한글 발음에만 |
| 길게 | `-` | `-` | 장음 (일본어 おう/ええ/ー, 중국어·영어 긴 모음) |
| 이어서 빠르게 (연음) | `_` | `‿` | 단어 사이를 끊지 않고 붙여 읽는 곳 |
| 약하고 빠르게 | `(스)` | 작고 흐리게 | 일본어 무성화 모음 (です의 す), 영어 약음절, 약하게 읽는 기능어 |
| 잠깐 쉼 | `|` | 얇은 세로선 | 긴 문장의 끊어 읽는 위치 |
| 다른 읽기 | ` / ` (앞뒤 공백) | 그대로 | `욘 / 시`처럼 읽는 법이 두 가지일 때 |

- 기호 안에 기호를 넣지 않습니다. 예외로 `[ ]` 안에 `-`와 `_`는 쓸 수 있습니다.
- 숫자는 중국어 발음에서만 성조로 해석합니다. 그래서 일본어와 영어 발음에는 숫자를 쓰지 않습니다.
- 검색용 텍스트에서는 기호를 지우므로, `오하요`로 검색해도 `오[하요-]`가 걸립니다.

## 언어별 작성법

### 일본어 (도쿄 표준 악센트)
- 높게 발음하는 박(拍)을 `[ ]`로 묶습니다. 높은 구간이 끝나면 다음 박에서 내려갑니다.
- 平板型(내려가지 않음)은 둘째 박부터 끝까지 묶습니다. 예: `와[타시]`
- 頭高型: `[하]시` (箸) / 中高型: `코[코로]` (心)
- 무성화되는 す, し, く 등은 `( )`로 표시합니다. 예: `데(스)`, `마(스)`
- 예: `오[하요- 고자이마](스)`, `아[리]가토- 고[자이마](스)`

### 중국어 (普通话, 간체)
- 한자 칸에는 간체, 병음 칸에는 성조 기호가 붙은 병음(`nǐ hǎo`)을 씁니다.
- 병음은 초보자가 읽기 쉽도록 **음절마다 띄어 씁니다**. 예: `xiè xie`, `Zhōng guó` (음절 수 검증에도 씁니다)
- 한글 발음에서는 **병음 한 음절마다** 해당 한글 뒤에 성조 숫자를 붙입니다. 한 음절이 한글 두 글자여도 숫자는 하나입니다. 예: `하오3`
- 한글 발음은 **실제 소리**를 적습니다. 3성 연속 변조(你好 → ní hǎo)와 不/一 변조를 적용합니다. 병음 칸은 사전 표기를 그대로 씁니다.
- 경성은 `0`입니다. 예: `시에4 시에0` (谢谢)
- 성조 숫자의 개수는 병음 음절 수와 같아야 합니다 (검증 스크립트가 확인합니다).
- 권설음(zh/ch/sh/r)은 `즈/츠/스/르` 계열로, ü는 `위`로 적습니다. 예: `쭝1 구어2` (中国), `뉘3` (女)
- b/d/g/z/zh는 단어 첫머리에서 된소리(ㅃ/ㄸ/ㄲ/ㅉ), 단어 안쪽에서 예사소리(ㅂ/ㄷ/ㄱ/ㅈ)로 적습니다. j는 항상 ㅈ입니다.

### 영어 (미국식)
- 단어의 1차 강세 음절을 `[ ]`로 묶습니다. 내용어(명사, 동사, 형용사)만 표시하고 기능어는 약하게 `( )` 처리할 수 있습니다.
- 자음과 모음이 이어지는 연음은 `_`로 표시합니다. 예: `[체]크_[아]웃`, `(어)` 
- 예: `굿 [모]닝`, `[땡]_큐`, `익스[큐-]즈_미`
