## v1.1: 4개 언어와 발음 표기
**In**
- 중국어(간체, 普通话) 열 추가: 한자, 병음, 한글 발음(성조 표시)
- 영어 한글 발음 추가 (강세, 연음, 약음)
- 일본어 한글 발음에 도쿄 악센트(높낮이)와 무성화 표기 추가
- 1단계 "발음 표기 읽는 법", "중국어 병음과 성조" 섹션
- 보기 설정의 "공부할 언어" 토글 (JS 없이도 동작, JS 모드에서는 기억)
- 버전 문서 체계 (`CLAUDE.md`, `CHANGELOG.md`, `docs/`)

**Out**
- 단계 재편, 새 주제 콘텐츠 (v1.2 이후)

## v1.2: 기본 / 중급 / 심화
**In**
- 단계 이름과 구성을 기본/중급/심화로 바꿉니다. 지금의 기본/회화/고급 내용을 다시 배치합니다.
- 단계마다 맨 앞에 **개념** 섹션을 둡니다. 언어별 문법을 비교 표와 짧은 설명으로 보여줍니다.
  - 기본: 어순, 조사, 시제
  - 중급: 활용, 조동사, 양사
  - 심화: 경어, 가정법, 보어
- 기존 섹션마다 항목을 보강합니다. 기본 단어는 섹션당 20개 이상을 목표로 합니다.

**Out**
- 여행, 문제, TOEIC

## v2.4: 주제별 페이지 (완료)
한 단계의 모든 주제가 한 페이지에 나와서 너무 길었습니다 (iPhone 13에서 1단계가 화면 약 200개 분량). 주제 하나를 한 페이지로 나눕니다.

**In**
- 단계 페이지(`/basic` 등)는 **주제 목록**: 학습 순서대로 묶은 파트(`parts`), 주제별 종류·개수, 완료 표시, 이어서 보기
- **주제 페이지** `/basic/greet`처럼 주제마다 주소 하나: 내용 → 문제 풀기 → 이전/다음 주제
  - 데스크톱은 왼쪽에 단계의 주제 목록, 모바일은 위에 목록으로 가기와 위치(9 / 18)
  - 마지막 주제 다음은 다음 단계로 이어짐
- 검색은 단계 전체: 단계 페이지에서 바로 걸러 보고, 주제 페이지에서는 Enter로 단계 검색 결과로 이동
- 진도: 주제 끝까지 보면 완료(`tri.done`), 마지막으로 본 주제(`tri.last`)를 홈과 단계 페이지에서 이어 보기
- 예전 주소 `/basic#s1-greet`는 새 주제 주소로 넘겨줌
- prerender 목록은 데이터에서 자동으로 만듦 (주제가 늘어도 손댈 곳 없음)

**Out**
- 단일 HTML 구조 변경 (지금처럼 한 페이지 유지)
- 플래시카드(한 장씩 넘기기) 학습 모드

## v2.4.1: PWA 자동 업데이트 (완료)
배포해도 홈 화면 앱이 옛 버전에 머물렀습니다. 새 버전 확인을 브라우저에만 맡겼고(앱 안 이동과 백그라운드 복귀 때는 확인하지 않음), 받은 뒤에도 화면에 적용하지 않았기 때문입니다.

**In**
- 새 버전 확인: 앱 시작, 백그라운드에서 복귀(1분에 한 번까지), 켜 둔 동안 30분마다
- 적용: 실행 직후 5초 안이면 바로 새로고침하고 "새 버전으로 업데이트했어요" 안내. 사용 중이면 다음 링크를 누를 때나 앱을 백그라운드로 보낼 때. 문제 풀기·보여 주기 카드가 열려 있으면 미룸
- 첫 설치는 업데이트로 보지 않음
- footer에 빌드 시각과 커밋 (`v2.4.1 · 11-28 14:05 · abc1234`)

**Out**
- 업데이트 알림 배너나 "지금 업데이트" 버튼 (자동 적용으로 대신함)

## v2.4.2: PWA 업데이트 크기 줄이기 (완료)
v2.4에서 주제 페이지가 생기면서 새 버전을 받을 때 미리 받는 파일이 173개(5.5MB)가 됐습니다. 아이폰 홈 화면 앱은 받는 도중에 앱을 닫으면 설치가 끊겨, 옛 버전에 머무르기 쉬웠습니다.

**In**
- 미리 받기(precache): 앱 뼈대(JS·CSS·아이콘), 홈, 404, 홈·단계 목록의 데이터(`.data`)
- 페이지 이동(HTML): 온라인이면 항상 네트워크에서 새로. 오프라인이면 앱 뼈대(`404.html`)로 열고 데이터로 그림
- 주제 데이터: 한 번 연 주제만 저장(온라인이면 새로 받음). 새 버전이 되면 옛 버전 저장분은 지움
- 오프라인에서 아직 열어 보지 않은 주제는 "오프라인이라 열 수 없어요" 안내

**Out**
- 주제 미리 받기 버튼 (필요하면 다음 버전)
