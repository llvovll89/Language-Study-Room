# 로드맵

학습자는 한국어만 아는 사람으로 가정합니다. 외국어(일본어, 중국어, 영어)는 처음 배운다고 봅니다.

| 버전 | 상태 | 주제 |
|---|---|---|
| v1.0 | ✅ 완료 | 한·일·영 3개 언어, 3단계(기본/회화/고급) |
| v1.1 | ✅ 완료 | 중국어 추가, 모든 외국어에 한글 발음과 높낮이·속도 표기, 언어 선택 |
| v1.1.1 | ✅ 완료 | README, 테스트 확대 (단위 테스트, 구조·접근성 E2E) |
| v1.2 | ✅ 완료 | 기본/중급/심화로 재편, 개념(문법) 섹션 먼저, 기존 내용 보강 |
| v2.0 | ✅ 완료 | React + TS + Tailwind 웹앱 전환 (Vercel, prerender, PWA). 단일 HTML은 유지 |
| v2.0.1 | ✅ 완료 | 성능: 콘텐츠를 loader로 옮겨 클라이언트 번들에서 데이터 제거 |
| v2.1 | ✅ 완료 | 여행 탭: 장면별 회화, 메뉴판, 표지판, 보여 주기 카드 |
| v2.2 | ✅ 완료 | 문제와 풀이 |
| v2.3 | ✅ 완료 | TOEIC 탭: 공식 시험 구성, 파트별 표현, 주제별 어휘, Part 5 문법과 문제 |

> v1.3~v1.5로 잡았던 기능은 웹앱 전환(v2.0) 뒤로 옮겨 v2.1~v2.3이 됐습니다. 새 기능은 웹앱에만 추가합니다.

## v1.1: 4개 언어와 발음 표기
**In**
- 중국어(간체, 普通话) 열 추가: 한자, 병음, 한글 발음(성조 표시)
- 영어 한글 발음 추가 (강세, 연음, 약음)
- 일본어 한글 발음에 도쿄 악센트(높낮이)와 무성화 표기 추가
- 1단계 "발음 표기 읽는 법", "중국어 병음과 성조" 섹션
- 보기 설정의 "공부할 언어" 토글 (JS 없이도 동작, JS 모드에서는 기억)
- 버전 문서 체계 (`CLAUDE.md`, `CHANGELOG.md`, `docs/`)

**Out**
- 단계 재편, 새 주제 콘텐츠 (v1.2 이후)

## v1.2: 기본 / 중급 / 심화
**In**
- 단계 이름과 구성을 기본/중급/심화로 바꿉니다. 지금의 기본/회화/고급 내용을 다시 배치합니다.
- 단계마다 맨 앞에 **개념** 섹션을 둡니다. 언어별 문법을 비교 표와 짧은 설명으로 보여줍니다.
  - 기본: 어순, 조사, 시제
  - 중급: 활용, 조동사, 양사
  - 심화: 경어, 가정법, 보어
- 기존 섹션마다 항목을 보강합니다. 기본 단어는 섹션당 20개 이상을 목표로 합니다.

**Out**
- 여행, 문제, TOEIC

## v2.0: 웹앱 전환
**In**
- `web/`: React 19, React Router 8 framework mode(`ssr:false` + prerender), TypeScript, Tailwind v4
- `data/`와 `lib/pron.mjs`를 단일 HTML 빌드와 함께 씀 (콘텐츠 단일 원본)
- 기존 기능 동등 (4개 언어, 발음 표기, 검색, 가리기, 공부할 언어, 발음 듣기, 개념 섹션, 글자표)
- 영문 URL: `/basic`, `/intermediate`, `/advanced`
- PWA: 홈 화면 추가, 오프라인
- Vercel 정적 배포 설정

**Out**
- 새 콘텐츠와 새 기능 (v2.1 이후)

## v2.1: 여행 대비
**In**
- 여행 회화: 공항, 숙소, 교통, 식당, 쇼핑, 긴급 상황
- 메뉴판 읽기: 일본, 중국, 영어권의 대표 메뉴명과 조리법, 맛 표현
- 표지판과 안내문: 出口, 禁止, Exit, Restroom 같은 것
- 보여 주기 카드: 화면을 상대에게 보여 주는 큰 글씨 카드
- 4번째 탭 `/travel` (웹앱 전용)
